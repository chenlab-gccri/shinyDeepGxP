Overview



shinyDeepGxP is a user-friendly web application for exploring and applying the DeepGxP model to single-cell RNA-seq data. It helps users predict surface protein abundance from transcriptomic profiles and inspect gene-level model interpretation results without requiring programming experience.

About DeepGxP

DeepGxP is a deep learning model that predicts surface protein abundance (measured by antibody-derived tags, ADTs) from single-cell RNA expression data. Trained on CITE-seq datasets with paired RNA and surface protein profiles, the model predicts the abundance of 224 surface proteins per cell. This enables multimodal single-cell analysis even when only RNA data are available.

DeepGxP was trained on a PBMC CITE-seq dataset (GSE164378) consisting of:

  • 53,364 cells
  • 19,738 input genes
  • 224 surface proteins

Because the model was trained on PBMC-derived immune cells, predictions are expected to be most reliable for human blood and immune-cell populations represented in the training data. Applications to non-blood tissues or biologically distinct cell types should be interpreted with caution.

The model predicts 224 proteins because these proteins were measured in the training CITE-seq dataset after quality control and removal of isotype controls. Proteins not included in the training data cannot be predicted.

DeepGxP is a data-driven deep learning model that learns relationships between gene expression and surface protein abundance directly from paired CITE-seq data. It does not use prior biological networks, pathways, or mechanistic constraints during training. To facilitate biological interpretation, DeepGxP is accompanied by the Integrated Gradients-based DeepEnrich framework developed alongside the model. DeepEnrich results can be explored through the Explore Model module.

ShinyDeepGxP Modules

Module 1: Explore Model

This module lets users explore precomputed model interpretation results. Users can select a cell type and surface protein to view important predictor genes and enriched biological pathways. No user-uploaded data are required for this module.

Module 2: Predict Protein

This module lets users upload a human scRNA-seq dataset and predict the abundance of 224 surface proteins. The module also performs clustering, reference-based cell type annotation, UMAP visualization, and result export.

Getting Started

  1. Use Explore Model to understand genes and pathways associated with protein prediction.
  2. Use Predict Proteins to analyze your own scRNA-seq dataset.
  3. Use the question mark icons beside each panel for detailed explanations of individual outputs.

Notes

  • The app is intended for research use.
  • The prediction model is PBMC-centered and performs best for human immune-cell datasets.
  • Input upload is needed only for the Predict Proteins module.
  • The Explore Model module uses precomputed interpretation results and does not require file upload.

For model details and citation information, please refer to the About page and the DeepGxP manuscript (Tsai et al. iScience 2026).
